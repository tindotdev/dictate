### Key Findings

1. **Architecture matters more than size**: GPT-OSS 20B (100%) outperforms Llama 70B (86%)
2. **Prompt-architecture interaction**: `cleanup_v2.txt` excels with GPT-OSS models but underperforms with Llama
3. **First perfect score**: `openai/gpt-oss-20b` + `cleanup_v2.txt` achieves 14/14 (100%) pass rate
4. **Production-stable winner**: The 20B model is production-ready (not preview) with 1000 tps speed and $0.30/M output cost

### Common Failure Patterns

#### 1. All-Filler Input (Test #12) — SOLVED by GPT-OSS

**Input**: `like like like um`
**Expected**: `` (empty string)
**Llama models**: Return meta-commentary (`"Nothing."`, `"No text to clean."`)
**GPT-OSS models**: ✅ Pass correctly (return empty string or single period)

**Impact**: GPT-OSS architecture handles edge cases that break all Llama models.

#### 2. Conversational Input (Test #14) — SOLVED by GPT-OSS

**Input**: `hey um can you help me with this code review`
**Expected**: `Can you help me with this code review?`
**Llama models**: Engage conversationally (`"I'd be happy to help..."`)
**GPT-OSS models**: ✅ Pass correctly (clean and return the question)

**Impact**: Different pretraining gives GPT-OSS better instruction-following.

#### 3. Over-Explanation (Test #4, llama-3.1-8b only)

**Input**: `we need to fix the kubernetes cluster and redeploy the nginx ingress`
**Expected**: Simple capitalization fix
**Failure**: 8B model generates 10+ sentence hallucination (Levenshtein: 0.05)

**Impact**: 8B model completely misunderstands task scope. **All other models pass this test.**

#### 4. Sentence Boundary Filler Removal (Test #3)

**Input**: `so basically um what happened was the server like crashed and uh we had to restart it`
**Expected**: `What happened was the server crashed and we had to restart it.`
**Challenge**: Requires removing sentence-initial fillers ("so basically")

**Impact**: Only 1/10 configurations pass; most models preserve "so basically" or similar phrases.

### Recommendations

#### For Production Use

1. **🏆 Default (NEW)**: `openai/gpt-oss-20b` + `cleanup_v2.txt`
   - **Perfect quality (100% pass rate)**

   - Fastest text model on Groq (1000 tps)
   - Cost-effective ($0.30/M output tokens)

2. **High Quality Alternative**: `openai/gpt-oss-120b` + `cleanup.txt`
   - 93% pass rate (second-best)

3. **Budget-Constrained (Llama fallback)**: `meta-llama/llama-4-scout-17b` + `cleanup.txt`
   - ⚠️ **Preview model** (may disappear)
   - 86% pass rate

4. **Avoid**:
   - `llama-3.1-8b-instant` (43-57% pass rate)
   - `cleanup_v2.txt` with Llama models (underperforms)
   - `cleanup.txt` with GPT-OSS models (slightly lower pass rate than cleanup_v2)

### Future Work

Potential improvements to evaluation:

- **Semantic similarity metrics**: Beyond lexical overlap (e.g., sentence embeddings)
- **User preference testing**: A/B test with real dictation sessions
- **Latency benchmarks**: Track inference time alongside quality
- **Cost analysis**: Balance quality vs. API costs
- **Streaming evaluation**: Test prompt performance with partial transcriptions
- **Multi-turn context**: How prompts handle longer dictation sessions
