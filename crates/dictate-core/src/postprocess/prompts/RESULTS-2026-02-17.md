Latest evaluation results from `just eval-matrix`. See [README.md](./README.md) for methodology.

## 2026-02-17

**Test Cases**: 14 golden scenarios
**Models Tested**: 3 (llama-3.1-8b-instant, meta-llama/llama-4-scout-17b-16e-instruct, llama-3.3-70b-versatile)
**Prompts Tested**: 2 (cleanup.txt, cleanup_v2.txt)

### Performance Summary

| Model                        | Prompt          | Pass Rate       | Avg Lev  | Avg ROUGE-1 |
| ---------------------------- | --------------- | --------------- | -------- | ----------- |
| **llama-3.3-70b-versatile**  | **cleanup.txt** | **12/14 (86%)** | **0.88** | **0.87**    |
| llama-3.3-70b-versatile      | cleanup_v2.txt  | 11/14 (79%)     | 0.88     | 0.84        |
| meta-llama/llama-4-scout-17b | cleanup.txt     | 12/14 (86%)     | 0.84     | 0.84        |
| meta-llama/llama-4-scout-17b | cleanup_v2.txt  | 10/14 (71%)     | 0.80     | 0.79        |
| llama-3.1-8b-instant         | cleanup.txt     | 8/14 (57%)      | 0.68     | 0.65        |
| llama-3.1-8b-instant         | cleanup_v2.txt  | 6/14 (43%)      | 0.69     | 0.63        |

### Key Findings

1. **Model size matters**: 70B > 17B > 8B in both pass rate and similarity scores
2. **Prompt quality matters**: `cleanup.txt` consistently outperforms `cleanup_v2.txt`
3. **Best configuration**: `llama-3.3-70b-versatile` + `cleanup.txt` for production
4. **Cost/performance trade-off**: `meta-llama/llama-4-scout-17b` + `cleanup.txt` offers 86% pass rate at lower cost

### Common Failure Patterns

#### 1. All-Filler Input (Test #12)

**Input**: `like like like um`
**Expected**: `` (empty string)
**Failure**: All models return meta-commentary instead of cleaned text

**Examples**:

- `"There is no text to clean up. Please provide the voice transcript text."`
- `"Removed filler words."`
- `"Nothing."`

**Impact**: Breaks task contract by explaining rather than outputting result.

#### 2. Conversational Input (Test #14)

**Input**: `hey um can you help me with this code review`
**Expected**: `Can you help me with this code review?`
**Failure**: Models engage conversationally instead of cleaning

**Example**: `"I'd be happy to help with your code review. What language is the code written in..."`

**Impact**: Fails 4/6 configurations; models misinterpret task as chat.

#### 3. Over-Explanation (Test #4, llama-3.1-8b only)

**Input**: `we need to fix the kubernetes cluster and redeploy the nginx ingress`
**Expected**: Simple capitalization fix
**Failure**: 10+ sentence hallucination with step-by-step instructions (Levenshtein: 0.05)

**Impact**: Smaller model completely misunderstands task scope.

#### 4. Meaning Preservation (Test #13)

**Input**: `I actually like this approach it's not like the old one`
**Expected**: Preserve both "like" instances (verb and comparison)
**Failure**: Smaller models change meaning, e.g., `"I prefer this new method it's much more efficient."`

**Impact**: 8B model struggles with context-dependent word sense.

### Recommendations

#### For Production Use

1. **Default**: `llama-3.3-70b-versatile` + `cleanup.txt`
   - Highest quality (86% pass rate)
   - Best handling of edge cases
   - Acceptable latency for most use cases

2. **Budget/Latency-Constrained**: `meta-llama/llama-4-scout-17b` + `cleanup.txt`
   - Still achieves 86% pass rate
   - Faster inference
   - Lower API costs

3. **Avoid**: `llama-3.1-8b-instant` (43-57% pass rate)
4. **Avoid**: `cleanup_v2.txt` prompt (underperforms across all models)

### Future Work

Potential improvements to evaluation:

- **Semantic similarity metrics**: Beyond lexical overlap (e.g., sentence embeddings)
- **User preference testing**: A/B test with real dictation sessions
- **Latency benchmarks**: Track inference time alongside quality
- **Cost analysis**: Balance quality vs. API costs
- **Streaming evaluation**: Test prompt performance with partial transcriptions
- **Multi-turn context**: How prompts handle longer dictation sessions
